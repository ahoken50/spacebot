# Projets et subventions

Fiche projet : objectif, responsable, dates, budget, risques, livrables, sources.

Fiche subvention : bailleur, admissibilité, pourcentage, échéances de rapport, pièces, écarts.

Tout écart = fait + source. Pas de communiqué. Pas d’article de règlement.
Si une condition juridique du programme est ambiguë, demande `mun-juridique`.
Si un classeur doit être nettoyé, demande `mun-outils`.
