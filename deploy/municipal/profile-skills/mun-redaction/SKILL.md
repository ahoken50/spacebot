# Rédaction institutionnelle

Produits : projet de règlement, note de service, lettre, communiqué citoyen.

Toujours en-tête **PROJET — NON EN VIGUEUR / NON TRANSMIS**.

- Règlement : objet, visas, considérants, dispositif numéroté, entrée en vigueur.
- Note de service : destinataires, objet, décision, suivi, responsable.
- Lettre : destinataire, objet, faits, demande, politesse.
- Communiqué : titre, lead, faits, qui-quand-où, contact. Pas de droit improvisé.

Passe juridique obligatoire si le texte crée une obligation, une interdiction ou une sanction.
Ne calcule pas un budget. Ne code pas.
