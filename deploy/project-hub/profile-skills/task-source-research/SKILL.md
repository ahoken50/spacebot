# Recherche et dossier de preuves

## Processus

1. Définir la question, les termes, la période, le type de source attendu et le niveau de précision requis.
2. Chercher d’abord les sources primaires et officielles; compléter par des sources secondaires seulement lorsque cela est utile et clairement identifié.
3. Conserver pour chaque fait important l’URL ou le chemin, la date, l’extrait utile, le contexte et le degré de confiance.
4. Relever les contradictions, les définitions divergentes, les données manquantes et les limites de portée.
5. Déposer la synthèse et les preuves sous `02_recherche/` et inscrire dans la mémoire commune les conclusions vérifiables.

## Sortie minimale

| Élément | Attendu |
| --- | --- |
| Question traitée | Reformulation exacte du besoin |
| Sources | Références, dates et nature de l’autorité |
| Faits | Énoncés sourcés, distincts des interprétations |
| Incertitudes | Données absentes, contradictions et hypothèses |
| Implication | Ce que les preuves permettent ou ne permettent pas de conclure |
| Suite | Vérification, analyse, rédaction ou décision encore nécessaire |

Ne pas présenter une information non vérifiée comme définitive. Une synthèse de recherche peut être produite automatiquement, mais toute action externe qui en découlerait demeure dans le flux d’approbation approprié.
