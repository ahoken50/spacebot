# Recherche de subventions municipales

1. Consulter d’abord `00_systeme/veille-municipale/` et les fiches approuvées afin d’éviter de répéter une recherche ou d’utiliser une source périmée.
2. Rechercher uniquement des sources institutionnelles ou le site officiel de l’organisme financeur. Conserver l’URL, la date de consultation, le titre du programme et le document de règles.
3. Produire une fiche de décision dans `06_rapports_et_syntheses/01_notes/` : objectif, porteur, territoire, montant et durée publiés, échéance, dépenses admises ou exclues, partenaires, pièces requises, risques, questions ouvertes et liens source.
4. Employer les termes **à confirmer** pour l’admissibilité, l’interprétation d’une règle, les coûts indirects, le cumul d’aide ou toute exigence institutionnelle. Ne pas annoncer qu’un projet est admissible sans validation par la personne responsable.
5. Préparer un calendrier de préparation seulement après validation humaine du programme retenu. Ne jamais créer de compte, transmettre une information, accepter une condition ni déposer une demande.
6. Distinguer clairement la donnée source, l’inférence de travail et la décision humaine. Consigner la date de la prochaine vérification lorsque l’appel n’est pas encore ouvert ou que les règles peuvent changer.

## Sources minimales

Utiliser selon la pertinence les organismes fédéraux et québécois, les ministères, la FCI, les FRQ, les programmes municipaux ou régionaux et les appels d’organismes partenaires. Une publication observée dans la veille est un signal; le document d’appel officiel reste la source de référence.
